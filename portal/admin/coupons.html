Discounts & free passes

A code students type at checkout. Points come off the class fee first; a % code then discounts the nett balance (S$-off and free passes still come off the full fee, and a code left with nothing to discount is not consumed). Rebate is always earned on cash actually paid — a free pass earns nothing. Tick Reusable to let a student use the same code on more than one course; otherwise every code is one use per student. Corporate “as quoted” classes (Claude Corporate Full Day and any corporate course added later) only accept their own company code — a code scoped to that course or family — unless it is marked 🏢 Corporate, which lets an any-course code open those classes too.
