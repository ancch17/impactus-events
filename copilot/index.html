    The afternoon session

    Build your own Copilot personal agent. No code.

    A Copilot personal agent is Copilot set up for one job, with your instructions built in. You write them once. After that, one click and it does the job the same way every time.

    1. Pick a task you repeat

      The weekly report. Meeting minutes. The same kind of email reply.

    2. Describe it in plain English

      Copilot's Agent Builder turns your description into a first version.

    3. Add instructions and starter prompts

      Your format, your tone, what it must never do.

    4. Test it, refine it, keep it

      Try it on sample work, tighten the instructions, and it's yours to use on Monday.

    Minutes Maker

    Paste rough notes. Get clean minutes and an action table with owners and dates.

    Reply in My Voice

    Drafts email replies in your tone, in the structure your manager likes.

    Weekly Report Writer

    Turns your bullet points into the same report format every Friday.

    Customer Letter Checker

    Checks a draft for tone, clarity and missing details before you send it.
